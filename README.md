Week 0 – Solar Data Discovery Project
📌 Overview

This project is part of the Kifiya AI Mastery Program (KAIM) Week 0 internship.
The task focuses on data discovery, environment setup, and using Git/GitHub like a real AI engineer.

The dataset contains solar energy production and weather-related features.

🎯 Project Goals

Understand the solar dataset
Perform data profiling and exploratory analysis
Practice clean development setup
Document insights in a professional report

🧠 Problem Statement

Solar companies often struggle to predict how much energy their panels will produce under different weather conditions.
This project explores:
How sunlight hours affect energy output
How temperature and humidity correlate with production
How weather variability impacts performance

📑 Key Insights

Energy output increases with higher sunlight hours.
Very high temperatures may reduce efficiency.
Cloudy or rainy conditions reduce output.
Dataset is suitable for predictive modeling in future weeks.
